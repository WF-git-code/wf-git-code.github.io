Python 基础语法自学笔记

一、基础规则与运行常识

1. 核心语法铁则

  1. 代码块不用大括号

    ，统一靠

    4 个空格缩进

    区分层级，缩进不一致直接报语法错误

    ⚠️ 坑：禁止 Tab 和空格混用；if、for、def、class 等行末尾必须加冒号

  2. 动态弱类型：变量无需提前声明类型，赋值即创建，同一变量可随时更换存储类型

  3. 语句结尾无需写分号 ;，加了不会报错，但不符合编码规范

  4. 布尔值固定首字母大写：True / False，小写 true/false 直接报错

  5. 字符串单引号 ''、双引号 "" 完全等价，无功能区别

  6. 所有序列（字符串、列表、元组）下标从 0 开始，支持负数下标（-1 代表最后一个元素）

2. 运行方式

  • 交互式：终端输入 python3 进入命令行，逐行执行，适合测试小段代码
  • 脚本式：代码写入 .py 文件，终端执行 python3 文件名.py 批量运行

3. 命名规范

  • 变量、函数名：蛇形命名法，小写字母 + 下划线，如 user_name、get_data
  • 禁止数字开头，禁止使用 Python 关键字（if、for、def、class、import 等）
  • 常量习惯全大写，如 MAX_SIZE = 1024

二、输入输出、注释、变量

1. print 输出

基础语法：print(内容1, 内容2, ...)

  • 多个内容自动用空格分隔
  • f-string 格式化（最常用，拼接变量最简洁）
  • 可选参数：sep 自定义分隔符，end 自定义结尾符

⚠️ 坑：f-string 大括号内只能写变量或简单表达式，不能嵌套复杂多行逻辑

2. input 输入

语法：input("提示文字")，接收用户输入，返回值永远是字符串类型

⚠️ 坑：直接用 input 结果做数值比较会报错，必须先通过 int() / float() 强转

3. 注释

  • 单行注释：# 注释内容，对应 C++ //

  • 多行注释：三对双引号

    或三对单引号，对应 C++

    ⚠️ 坑：多行注释不能拆分插入单行代码中间，必须独立成行

4. 变量与类型查看

  • 定义：直接 变量名 = 值
  • 查看类型：type(变量)，调试时常用

⚠️ 坑：变量必须先赋值再使用，引用未定义变量会抛出 NameError

三、基础数据类型

1. int 整型

  • 正负整数，无数值大小限制
  • 支持二进制 0b、八进制 0o、十六进制 0x 写法

2. float 浮点型

  • 对应 C++ double，存储小数

    ⚠️ 坑：浮点数运算存在精度丢失（如 0.1 + 0.2 ≠ 0.3），高精度计算需用 decimal 模块

3. str 字符串（高频使用）

  • 有序字符序列，属于不可变类型
  • 常用操作：
    • len(s)：获取字符串长度
    • s[index]：按下标取单个字符
    • s.strip()：去除首尾空格 / 换行
    • s.split(分隔符)：按分隔符切割，返回列表
    • s.replace(old, new)：替换指定内容
    • s.upper() / s.lower()：大小写转换
    • 切片：s[起始:结束:步长]，左闭右开

⚠️ 坑：字符串不可变，不能通过 s[0] = 'a' 修改单个字符，修改会生成新字符串

4. bool 布尔型

  • 仅两个值：True、False

  • 逻辑运算符：

    （且）、

    （或）、

    （非）

    ⚠️ 坑：禁止使用 C++ 风格

    ，写了直接语法报错

5. None 空值

  • 对应 C++ nullptr，代表 “无数据”

    ⚠️ 坑：判断空值统一用

    ，不要用

    ；不存在 null 关键字

常用类型转换

  • int(x)：转整数
  • float(x)：转浮点数
  • str(x)：转字符串
  • bool(x)：转布尔值，0、空字符串、空容器、None 均为 False

四、四大容器类型（核心重点，对标 C++ 容器）

1. list 列表 ≈ C++ vector

特性：可变、有序、支持任意类型元素、动态扩容

基础操作

常用方法

  • lst.append(x)：尾部追加元素
  • lst.insert(index, x)：指定下标插入
  • lst.extend(可迭代对象)：尾部批量追加
  • lst.pop()：删除尾部元素并返回；lst.pop(index) 删除指定下标
  • lst.remove(x)：删除第一个匹配的元素
  • lst.index(x)：查找元素第一次出现的下标
  • lst.count(x)：统计元素出现次数
  • lst.sort()：原地排序；sorted(lst) 返回排序后的新列表
  • lst.reverse()：原地反转

切片操作

语法：lst[起始:结束:步长]，左闭右开，结束下标取不到

常见坑点

  1. 下标直接访问越界会报错；切片越界不会报错，只返回现有元素
  2. list 是可变类型，不能作为字典的 key
  3. 遍历列表时同步删除元素，会导致下标错乱、元素遍历遗漏
  4. 直接 lst2 = lst1 是引用赋值，修改一个另一个同步变化；拷贝用 lst.copy() 或 lst[:]（浅拷贝）

2. tuple 元组 ≈ C++ const 数组

特性：不可变、有序、创建后无法增删改

常见坑点

  1. 单元素元组必须加逗号：t = (1,)，不加括号会被识别为普通变量
  2. 元组不可变指的是元素的内存地址不可变；若内部嵌套 list，list 内部元素可修改
  3. 可作为字典 key，list 不行

3. dict 字典 ≈ C++ unordered_map

特性：键值对存储、key 必须是不可变类型（int/str/tuple）、Python3.7+ 插入有序

基础操作

常用方法

  • dict.get(key, 默认值)：key 不存在返回默认值，不抛异常
  • dict.keys()：获取所有键
  • dict.values()：获取所有值
  • dict.items()：获取所有键值对
  • dict.update(新字典)：批量合并键值对
  • dict.pop(key)：删除指定 key 并返回 value

三种遍历方式（面试高频）

常见坑点

  1. 直接用 dict[key] 访问不存在的 key，会抛出 KeyError 中断程序，优先用 get 方法
  2. list、dict、set 等可变类型不能作为 key
  3. 低版本 Python（3.7 以下）字典无序，不要依赖插入顺序

4. set 集合

特性：自动去重、无序、无下标、元素必须是不可变类型

常用操作

  • s.add(x)：添加元素
  • s.remove(x)：删除元素
  • 集合运算：交集 &、并集 |、差集 -

常见坑点

  1. 无法通过下标取值，需要索引访问需先转为 list
  2. 空集合必须用 set() 创建，{} 创建的是空字典

** 幂运算 如 2**3 = 8

⚠️ 坑：想要整数结果必须用 //，/ 哪怕能整除也返回 float

3. 比较运算符

⚠️ 坑：赋值 = 和相等判断 == 极易写混，条件判断里注意检查

4. 逻辑运算符

优先级：not > and > or

5. 成员运算符

in / not in：判断元素是否在容器中

6. 身份运算符

is / is not：判断两个变量是否指向同一个内存对象

⚠️ 坑：== 判断值是否相等，is 判断内存地址是否相同；小整数池范围内小整数 is 为 True，大整数不保证

六、流程控制

1. 条件判断 if /elif/else

语法：条件后加冒号，下一行缩进写代码块

⚠️ 坑：忘记写冒号、缩进错乱是最高频语法错误；Python 无 switch 语句

2. 三元表达式

语法：结果1 if 条件 else 结果2

简化简单二选一逻辑，替代短 if

⚠️ 坑：仅支持单行表达式，复杂多层判断不建议用，可读性差

3. for 循环

两种核心用法：

  1. 遍历容器（列表、字符串、字典等）
  2. 配合 range () 生成数字序列

⚠️ 坑：range(n) 只生成 0 ~ n-1，取不到 n；循环中修改列表长度会打乱遍历逻辑

4. while 循环

条件成立则持续执行，适合未知循环次数的场景

⚠️ 坑：忘记更新循环变量会导致死循环

5. break 与 continue

  • break：直接终止当前整个循环

  • continue

## 九、高频易错点总览

1. 缩进错误、行尾漏冒号、布尔值小写，是新手 Top3 语法报错原因
2. 可变类型（list/dict/set）不能做字典 key；不可变类型（int/str/tuple）可以
3. 字符串、元组不可变，禁止通过下标修改内部元素
4. 区分赋值 `=` 和相等判断 `==`
5. 逻辑运算只用 `and/or/not`，禁止 C++ 风格符号
6. input 返回值默认字符串，数值计算必须强转
7. 字典访问未知 key 优先用 get 方法，避免 KeyError
8. 列表直接赋值是引用，拷贝需用 copy () 或切片
9. 单元素元组必须加逗号
10. 默认参数不要用可变类型
